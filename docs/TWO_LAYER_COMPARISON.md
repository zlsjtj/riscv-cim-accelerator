# 两层 pointwise 的 K7 50 MHz 对照

2026-11-06，`xc7k325tffg900-2` 的同一位流 `43494d48`、同一
RV32IM 固件、同一输入和参数，运行六条路径。第一层使用实际导出的
tensor23 激活，第二层权重和参数由固定种子生成。两层各为 64×64
INT8 pointwise，M1/M125 均逐字节验证中间和最终结果。12 次任务
累计比较 96,768 字节，零失配。

计时从输入就绪后的计时器启动，到 CPU 读到最终输出末字并提交
停表。包含任务配置、START、轮询、核执行及最终读，排除数据准备、
golden 比较和 UART。两次 START 和一次 START 共用同一中间地址
`0x80106000` 和最终地址 `0x80108000`。

SRAM 计数为同固件 SoC 仿真的加速器握手数，以 32 位字计。RV32IM
C 通过 CPU 自身端口访问，表中未用加速器计数表示其访存。M1 的
方法 0/1 各读写 2,464/32 字，方法 3/4/5 各读写 2,448/32 字。

M125 从两次 START 到最终路径累计少 7,467 拍（149.34 µs，15.82%），
相对同 SoC 的 RV32IM C 延迟比为 138.27×。M1 累计少 164 拍
（3.28 µs，1.68%），相对 C 延迟比为 4.79×。各步比例分别使用
上一步的周期作分母。保留移除 2,000 个中间 SRAM 读字。提前回放和
提前写回通过重叠减少周期，访问量见上表。

最终位流由 `777c941` 的硬件和固件入口生成，`3c91e8a` 封存对应
证据。核对了板测 UART、编程回读 ID、位流 SHA-256、固件 ELF 和
SRAM 镜像。20 ns 布线的 WNS/WHS 为 +6.071/+0.085 ns，整板
16,376 LUT、11,233 FF、20 RAMB36、8 DSP。
