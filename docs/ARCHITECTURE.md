# 数据流与逐拍合同

固定 K=N=64，M=1..125。tile 是 8 个输出通道；外层遍历 8 个 tile，
先读取 24 个参数字和 128 个权重字，再处理该 tile 的 M 个输入向量。
权重在宏内部驻留，输入每个 tile 重读。没有隐藏 DMA 或宽存储端口。

输入字节 q 翻转 MSB 得到 U8 的 q+128，拆成两个 U4。权重每个字节
映射到两个相邻宏列：低列 U4、高列 S4。每轮宏产生 16 个 14bit 原生
结果，偶数列零扩展、奇数列符号扩展至 INT32，先移位再重建。低输入
分片的部分和保存在块上下文；高分片到达后再移位合并，并加一次 bias。
没有额外的 128*sum(weights) 修正。

## 宏时序

所有事件位于同一主时钟上升沿。这里的拍数是本数字代理的主时钟拍数。

|边沿|行为|
|---|---|
|E0|start && start_ready 接受；清空 16 个位串行累加器|
|E1|采样 A4 bit3 的 64bit 位平面|
|E2|采样 bit2|
|E3|采样 bit1|
|E4|采样 bit0；边沿后 result_valid=1，busy=0|
|E5|外围消费上一结果；宏最早可接受下一 start；valid 默认撤销|

从接受到结果寄存器有效 latency=4，最小 start II=5。没有输出 ready。
每个平面对各列进行 K64 权重选择和加和，再更新 `accum*2+plane_sum`。
偶数列最大结果14400，奇数列范围[-7680,6720]。权重写只在 idle 接受，
在接受边沿提交；同时编程和 start 时编程优先。主时钟没有派生时钟。
reset 终止操作并清除 busy/valid/外围状态，权重存储不复位；新任务必须
重新装完权重才允许计算。这不是物理 CiM 宏时序或能效的复现。

## 有限容量与模式

MODE=0 只允许一个块存活，形成完整阻塞基线；MODE=1 允许两个块。
两个模式共享同一宏、同一 32bit 共享存储端口、同一个量化单元。

- 两个输入槽，每槽 64B，以低/高 nibble 各 256bit 保存；整个块存活时保留。
- 两个原生结果槽，每槽 224bit，加 ctx/slice 标签和占用/预约位。
- 两个输出块上下文，各保存 8 个 INT32 部分和、p、分片状态、量化进度、
  最终 8 个 INT8 及写回进度。tile 全局固定，跨 tile 前必须排空。
- 宏 start 前预约空原生结果槽；无论存储 ready 如何变化，宏结果都写入
  已预约的槽。原生包弹出不会释放块上下文。
- 量化每拍可发射一个通道，II=1。第一个沿捕获有符号 64bit 乘积、移位、
  特殊饱和位及有效的上下文和通道号。下一沿把按原有双舍入和饱和规则得到
  的 INT8 写入该上下文。发射计数到 8 即停止该块继续发射，通道 7 实际
  落入输出缓存后才开放写回。两个 32bit 写请求均被接受并提交后释放上下文。

相对仅一个输入槽、一个原生槽、一个上下文的容量，第二套数据存储增加
512+224+256+64=1056bit，另外需要标签、计数器和控制。当前两个MODE来自
同一网表，阻塞MODE也保留这些物理资源；没有用模式周期差冒充独立面积
增量，也尚未综合一个裁剪成单上下文的网表来测资源差。

复位清除量化流水有效位并清空上下文。乘积寄存器的内容只在对应有效位
为 1 时使用。任务排空检查包括量化有效位，最后写回提交后才置 DONE。
K7 布线和实测计数见 [v0.1 发布说明](RELEASE_v0.1.md)。结合具体 RTL 和
时序片段的讲解见 [DESIGN_WALKTHROUGH.md](DESIGN_WALKTHROUGH.md)。

## 存储与控制

请求寄存器在 valid && !ready 时保持不变。每拍最多接受一个32bit请求。
本实现有意限制为最多一个未返回读，读响应最早在接受后的下一拍返回，
且不能与另一个响应重叠。响应没有 ready，因此在请求前固定目的槽和索引。
输入槽的同一 16 字填充可在消费旧响应的同拍接受下一字。后续标签只在真正
接受后取代旧标签。若该拍背压，普通请求寄存器接管并保持 valid、地址和控制。
参数、权重、写回和输入槽切换仍用原登记路径。[请求周转证据](SRAM_TURNAROUND.md)
写 ready 表示真正提交；后续有写响应的真实总线必须由适配器延伸到提交点。

合法 START 锁存配置、清除 DONE/ERROR/计数器。运行时改配置只写影子寄存器。
重复 START 置 sticky ERROR，当前任务继续。硬件检查 M、MODE、地址4B对齐，
读取参数时检查 multiplier>=0 和 shift∈[-31,0]；驱动/准备工具另外检查
不重叠、地址不回绕和所有 U8 输入下的 INT32 累加器上下界。

最后写提交后，等待所有块、原生槽、预约、宏和内存事务排空再置 DONE。
DONE 保持至 ACK 或下一合法 START。总周期涵盖参数/权重加载和最终排空；
mem_wait 统计请求 valid && !ready，macro_cycles 统计 macro busy；两者可能
重叠，不得直接相加当作任务周期。读响应等待包含在总周期中。

reset 时外部适配器必须一起清理或排空旧响应；没有事务 ID 的端口不能将
reset 前的响应送入 reset 后的新任务。不能把 reset 当作暂停恢复。
